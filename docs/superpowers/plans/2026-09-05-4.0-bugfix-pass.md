# 4.0.x Bugfix Pass Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the eight operator-facing 4.0.x holes (board #1033–#1040): pairing URLs, QR, revoke live+push, Noise focus, IK oracle, group-kill copy, iOS 401 remint, device-token CLI, docs.

**Architecture:** Pairing URL inference is duplicated (TS + Swift) with identical cases. Revoke becomes a single `revokeDevice` that deletes the registry row, closes tracked live sockets, and deletes `push_devices` keyed by `auth_device_id`. Noise `{t:'focus', id, focused}` is per-attachment. IK registry-miss throws `handshake`. iOS REST shares one 401 remint helper.

**Tech Stack:** Bun + Hono + bun:test on the server; desktop Vite/React + Tauri Rust; iOS Swift/TetherKit (xcodebuild on macbuild). Biome 2-space, single quotes, width 100.

**Spec:** `docs/superpowers/specs/2026-09-05-4.0-bugfix-pass-design.md`

**Interfaces:**
- Consumes: existing `validateAddress(host, port)`
- Produces:

```ts
export type PairScheme = 'http' | 'https';
export function parsePairAddress(input: string):
  | { ok: true; scheme: PairScheme; host: string; port: string; wsAddress: string }
  | { ok: false; reason: string };

export function recordHostScheme(hostId: string, scheme: PairScheme): void;
export function hostScheme(hostId: string, port: string): PairScheme;
export function forgetHostScheme(hostId: string): void;
```

Rule (copy from spec §1, implement exactly):

- Trim. If `raw` contains `://`, keep that scheme (`http`/`https`/`ws`/`wss`; map `ws`→`http`, `wss`→`https` for stored REST scheme).
- Else no scheme: port `80` or `8085` → `http`; `443` or `8443` → `https`; any other port, or no port → `http`.
- No port after parsing: scheme `https`/`wss` → **443** (not 8443); scheme `http`/`ws` or inferred `http` → **8085**; bare host no scheme no port → **8085** + `http`.
- `wsAddress`: `https` → `wss://host:port/api/noise/pair`, else `ws://…`. Do **not** strip `https`/`wss` and rebuild `ws://`.
- Persist scheme in `localStorage` key `tether.host.schemes` (`Record<hostId, 'http'|'https'>`), same as iOS `HostScheme`. Fallback when missing: port `443`/`8443` → `https`, else `http`.
- `httpOriginFor(profile)` = `${hostScheme(profile.id, profile.port)}://${profile.host}:${profile.port}`.
- `pairHost` input gains `scheme: PairScheme`. After `coreHostsSaveNoise`, `recordHostScheme(profile.id, input.scheme)`. `forgetHostScheme` on host remove.
